### Aula 01 - Conceituando testes
<ul>
  <li>Alguns dos tipos de testes que podemos implementar, como: os estáticos, unitários, de integração e E2E;</li>
  <li>O que é ter uma cultura de testes e alguns de seus benefícios, como a padronização e estabelecimento de processos para o nosso projeto;</li>
  <li>Como utilizar o ESLint para fazer testes estáticos em JS estabelecendo um padrão de escrita para o código, verificando se há divergências entre o código escrito e o padrão adotado e também analisando a estrutura do projeto em busca de problemas como módulos inexistentes, falta de clareza nas declarações etc;</li>
  <li>A implementar os primeiros testes de unidade utilizando um código implementado do zero.</li>
</ul>
